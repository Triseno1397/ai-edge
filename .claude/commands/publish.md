Publish the desk to the live mobile dashboard: https://ai-edge-tau.vercel.app
(Vercel project `trisenos-projects/ai-edge`, connected to GitHub repo `Triseno1397/ai-edge` with
Root Directory = `web`). **Every push to `main` auto-deploys** — so publishing is just commit + push.

Do this:
1. `git add -A`
2. Commit with a dated message — e.g. `desk: brief 2026-06-17` (use the newest briefing date, or
   summarize what changed if it wasn't a briefing).
3. `git push origin main`. Vercel rebuilds automatically; the new content is on the phone in ~40–60s.

Notes:
- The web viewer never generates anything — it only renders what the desk has produced. Run `/brief`,
  `/disrupt`, or `/learn` FIRST, then `/publish`.
- The daily auto-brief routine already does this for you each morning; use `/publish` for an
  out-of-cycle update you generated by hand.
- Manual fallback (bypasses git): `npm --prefix web run deploy` runs a direct Vercel CLI deploy.
- The live site is on a public (unguessable) URL. To lock it down: Vercel Project → Settings →
  Deployment Protection.
