# Creative Playbook

The craft library — the techniques that separate a usable client deliverable from an obvious AI clip.
Organized by the problem you're trying to solve, not by tool, because the tools churn and the problems
don't. The `creative-scout` skill appends here whenever a briefing or a `/creative` run turns up a
technique worth keeping.

**Entry format**

~~~
### <The technique, named for what it fixes>
`VIDEO` `FILM` · added YYYY-MM-DD

What it fixes: <the failure mode>
How: <the actual steps — enough to run it, not a summary>
When it beats the obvious approach: <the tradeoff>
Source: <link>
~~~
