# Prompt Vault

The running library of prompts that actually produce work — viral formats, client-ready ad recipes, and
cinematic looks. The `creative-scout` skill appends here after every `/creative` run and after any briefing
that surfaces a prompt worth keeping. Entries are deduped; a better version of an existing prompt replaces
the old one rather than sitting next to it.

**Entry format**

~~~
### <Short name for what it produces>
`IMAGE` `ADS` · <model it was built for> · added YYYY-MM-DD

```
the full copy-paste prompt
```

Use it for: <the job this wins — product hero, UGC hook, establishing shot, etc.>
Swap: <the parts to change per client — product, palette, lens, motion>
Source: <link>
~~~

Tags: `IMAGE` `VIDEO` `AUDIO` for medium, `ADS` `FILM` for which side of the business it serves.
